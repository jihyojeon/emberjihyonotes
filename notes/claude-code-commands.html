✳
어디에 입력하나요?

Claude Code 입력창 맨 앞에 적으면 됩니다. /만 입력하면 지금 쓸 수 있는 목록이 나와요. 메뉴가 열리면 원하는 항목을 고르세요. 일반 Claude 웹 채팅과는 사용할 수 있는 기능이 다릅니다.

명령 뒤에 붙인 한국어는 업무 상황에 맞춰 쓴 예시예요. ../reference-data 같은 경로는 내 폴더 이름으로 바꿔주세요. 명령만 적힌 예시는 실행한 뒤 나오는 안내를 따르면 됩니다.

120개에는 같은 기능을 다른 이름으로 부르는 별칭 4개, 이미 삭제된 명령 3개도 포함돼요. 현재 쓸 수 있는 서로 다른 기능이 120개라는 뜻은 아닙니다. /design consent와 /design revoke는 한 항목으로 다뤘어요.

낯선 용어도 나와요. 세션은 하나의 작업 대화, 컨텍스트는 지금 참고할 수 있는 대화 공간을 말합니다. PR은 코드 변경 제안이고, 브랜치는 작업 갈래, 저장소는 프로젝트를 관리하는 공간이에요. 스킬은 반복 업무 매뉴얼, 아티팩트는 열어보거나 공유할 수 있는 결과물로 생각하면 됩니다.

01

처음 시작할 때

처음 접속했다면 도움말을 보고, 프로젝트에 필요한 규칙을 정해두세요.

6개
001기본 명령#

/help뭐부터 할 수 있지?

Help · 도움말

도움말과 지금 쓸 수 있는 명령 목록을 엽니다. 처음이라면 여기서 어떤 기능이 있는지 살펴보면 돼요.

이럴 때 쓰세요처음 접속했거나, 본 가이드의 명령이 내 화면에는 보이지 않을 때.

입력 예시
/help

입력창에 /만 적어도 사용할 수 있는 명령이 나옵니다.

002기본 명령#

/powerup이런 기능도 있었어?

Power up · 기능 익히기

짧은 설명과 움직이는 데모로 Claude Code의 기능을 익힐 수 있어요. 설명서를 길게 읽기 전에 직접 눌러보고 싶을 때 좋습니다.

이럴 때 쓰세요팀에서 Claude Code를 도입했고 직접 눌러보며 익히고 싶을 때.

입력 예시
/powerup

도구 사용법을 배우는 기능이에요. 업무 결과물을 만들어주는 명령은 아닙니다.

003기본 명령#

/init우리 프로젝트, 먼저 파악해줘

Initialize · 초기화

현재 프로젝트를 읽고 안내 파일 CLAUDE.md를 만듭니다. 클로드가 이 프로젝트에서 알아야 할 지침을 적어두는 파일이에요.

이럴 때 쓰세요팀의 업무 자동화 프로젝트 폴더에서 처음 Claude와 일할 때.

입력 예시
/init

회사 규칙을 자동으로 알아내지는 못해요. 만들어진 안내를 읽고 필요한 내용을 보태주세요.

004기본 명령먼저 써볼 10#

/memory매번 설명할 규칙은 여기 두자

Memory · 기억

프로젝트 지침인 CLAUDE.md와 자동 기억을 확인하고 관리합니다. 매번 설명하는 업무 규칙이 있다면 여기에 어떻게 저장돼 있는지 보세요.

이럴 때 쓰세요보고서는 결론부터 쓰고 금액은 원화로 표기한다는 기준을 관리할 때.

입력 예시
/memory

대화 기록 전체를 기억하는 기능은 아니에요. 개인 지침인지, 이 프로젝트에만 적용되는 지침인지도 확인해주세요.

005기본 명령먼저 써볼 10#

/plan일단 계획부터 잡자

Plan · 계획

계획 모드에 들어가 작업 순서부터 잡습니다. 할 일이 크거나 조건이 복잡할수록 순서부터 맞춰두는 편이 좋아요.

이럴 때 쓰세요월말 보고서 자동화를 맡기기 전에 필요한 자료와 진행 순서를 정할 때.

입력 예시
/plan 월말 실적 보고서 작성 과정을 자동화하고 싶어. 필요한 자료와 작업 순서부터 정리해줘.

계획을 읽고 실행으로 넘어가면 됩니다. 아직 계획만 세운 단계라는 점은 기억해주세요.

006기본 명령#

/output-style답변하는 방식을 바꾸자

Output style · 응답 스타일

등록된 응답 스타일을 보고 바꿀 수 있어요. 짧게 답을 받고 싶을 때, 설명을 들으며 배우고 싶을 때 각각 맞는 스타일을 고르면 됩니다.

이럴 때 쓰세요회의 직전이라 핵심만 빠르게 읽고 싶을 때.

입력 예시
/output-style concise

말투를 자유롭게 주문하는 것과는 별도로, 이 환경에 등록된 스타일을 고르는 기능이에요.

02

대화를 정리하고 이어갈 때

질문 하나만 하고 싶거나, 대화가 너무 길어졌거나, 전에 하던 일을 다시 찾을 때.

12개
007기본 명령먼저 써볼 10#

/btw하던 일은 그대로, 질문 하나만

By the way · 근데 잠깐만

By the way, 우리말로 하면 "근데 잠깐만" 정도예요. 지금 하는 일은 그대로 두고 질문 하나만 하고 싶을 때 씁니다. 질문과 답은 본 대화 기록에 들어가지 않아요.

이럴 때 쓰세요제안서를 작성하던 중 방금 나온 업무 용어만 확인하고 싶을 때.

입력 예시
/btw 방금 말한 KPI랑 OKR은 어떻게 달라?

질문을 덧붙이지 않고 /btw만 입력하면 최근에 물었던 내용을 다시 볼 수 있어요.

008기본 명령먼저 써볼 10#

/clear이제 다른 업무 시작하자

Clear · 비우기

대화 맥락을 비우고 새로 시작합니다. 오전에 보고서를 쓰고 오후에는 행사를 기획한다면, 새 업무를 시작할 때 이전 조건을 털어낼 수 있어요.

이럴 때 쓰세요이전 업무의 조건이 새 업무에 따라오는 것이 불편할 때.

입력 예시
/clear 월간 보고서 완료

파일은 지워지지 않아요. 이전 대화도 /resume으로 다시 찾을 수 있습니다. 별칭: /reset, /new.

같은 기능의 이름: /reset, /new

009기본 명령먼저 써볼 10#

/compact정리하고 계속 가자

Compact · 압축하기

길어진 대화를 요약해서 공간을 확보합니다. 수정 요청이 한참 쌓였는데 같은 일을 계속해야 할 때 쓰면 돼요.

이럴 때 쓰세요수정 요청이 여러 번 쌓였지만 확정된 방향은 유지해야 할 때.

입력 예시
/compact 확정된 보고서 목차, 핵심 수치, 남은 수정사항을 중심으로 정리해줘.

요약하면서 세부 내용은 줄어들 수 있어요. 꼭 남겨야 할 조건을 명령 뒤에 적어주세요.

010기본 명령#

/context대화 공간을 뭐가 차지하지?

Context · 현재 참고 중인 내용

대화 공간을 얼마나 쓰고 있는지 보여줍니다. 읽힌 자료나 연결 도구, 기억 중 무엇이 공간을 많이 차지하는지 볼 수 있어요.

이럴 때 쓰세요자료를 많이 읽힌 뒤 대화 공간이 부족해졌을 때.

입력 예시
/context all

공간을 확인한 뒤, 같은 일을 계속한다면 /compact를, 새 일을 시작한다면 /clear를 쓸 수 있습니다.

011기본 명령#

/autocompact얼마나 차면 자동으로 정리할까?

Auto compact · 자동 압축

대화가 얼마나 찼을 때 자동으로 요약할지 정합니다. 사용자 설정에도 저장되므로 다음 작업에도 영향을 줄 수 있어요.

이럴 때 쓰세요긴 작업에서 자동 정리 시점을 확인하거나 기본값으로 돌리고 싶을 때.

입력 예시
/autocompact auto

우선 인자 없이 실행해 현재 값을 보세요. 설정할 수 있는 크기와 적용 우선순위는 모델·환경에 따라 달라요.

012기본 명령#

/recap우리 지금 뭐 하고 있었지?

Recap · 짧은 되짚기

현재 대화에서 무엇을 하고 있는지 한 줄로 짚어줍니다. 회의에 다녀와서 "아까 어디까지 했더라?" 싶을 때 쓰기 좋아요.

이럴 때 쓰세요회의를 마치고 돌아왔는데 여러 대화 중 어디까지 했는지 헷갈릴 때.

입력 예시
/recap

상황을 빠르게 되짚는 요약이에요. 대화 공간을 줄이려면 /compact를 쓰세요.

013기본 명령#

/rename이 대화, 나중에 찾기 쉽게

Rename · 이름 바꾸기

대화에 이름을 붙입니다. 고객사나 날짜, 업무 이름을 적어두면 나중에 다시 찾기 편해요.

이럴 때 쓰세요제목만 보고도 어떤 고객사의 무슨 업무인지 알아보고 싶을 때.

입력 예시
/rename 10월 고객사 제안서

이름을 적지 않으면 클로드가 대화 내용을 보고 정해줍니다.

014기본 명령먼저 써볼 10#

/resume어제 하던 거 이어서 하자

Resume · 이어하기

전에 하던 대화를 다시 엽니다. 이름이나 ID를 입력해도 되고, 목록에서 골라도 돼요. 어제 설명한 내용을 오늘 다시 적지 않아도 됩니다.

이럴 때 쓰세요어제 작성하던 제안서 수정 작업을 오늘 이어갈 때.

입력 예시
/resume

/rename으로 이름을 붙여두면 목록에서 찾기 쉬워요. 별칭: /continue.

같은 기능의 이름: /continue

015기본 명령#

/branch이 방향도 한번 해보자

Branch · 갈래 만들기

지금까지의 대화를 남겨두고, 여기서 다른 방향으로 갈라집니다. 새 갈래로 이동해 작업하므로 원래 안을 보관한 채 다른 안을 시도할 수 있어요.

이럴 때 쓰세요보수적인 제안과 과감한 제안을 각각 비교하며 검토하고 싶을 때.

입력 예시
/branch 제안서-과감한-방향

/branch는 내가 새 갈래로 이동합니다. /fork는 복사한 세션이 따로 일하는 방식이에요.

016기본 명령먼저 써볼 10#

/rewind잠깐, 그 수정 전으로 가자

Rewind · 되감기

이전 체크포인트를 골라 대화나 코드 변경을 되돌립니다. 선택한 시점부터의 대화를 요약하는 용도로도 쓸 수 있어요.

이럴 때 쓰세요잘 작동하던 사내 도구를 수정한 뒤 문제가 생겼을 때.

입력 예시
/rewind

셸이나 외부 도구가 바꾼 내용은 복구되지 않을 수 있어요. 되돌릴 수 있는 범위를 보고 선택하세요. 별칭: /checkpoint, /undo.

같은 기능의 이름: /checkpoint, /undo

017기본 명령먼저 써볼 10#

/copy방금 답변 가져갈게

Copy · 복사

마지막 답변을 클립보드에 복사합니다. 뒤에 숫자를 적으면 몇 번째 이전 답변을 가져올지도 정할 수 있어요.
