터미널에서 쓰는 Claude Code

입력창에서 바로 쓰는 단축키

수정을 몇 번 맡겼는데 처음 것이 더 나을 때가 있어요. 입력창을 비우고 Esc를 두 번 누르면 돌아갈 시점을 고를 수 있습니다. 요청을 길게 쓰던 중에 다른 걸 먼저 확인하고 싶다면 Ctrl+S로 쓰던 글을 잠깐 보관해두세요.

단축키는 터미널에서 실행하는 Claude Code 기준이에요. 메뉴 안에서만 쓰는 키와 Vim 편집 키도 있습니다. Claude 웹 채팅이나 데스크톱 앱 자체에서는 다르게 동작할 수 있어요.

Ctrl+J

+는 같이 누르기.
Ctrl을 누른 채 J를 누르세요. Mac도 Ctrl이라고 적혀 있으면 Control 키를 씁니다.

Esc → Esc

→는 순서대로 누르기.
Esc를 누르고 뗀 뒤 한 번 더 누르세요. 화살표 키 자체를 누르라는 뜻은 아닙니다.

Ctrl+X → Ctrl+E도 두 조합을 순서대로 누릅니다. 연속 키는 앞 키를 누른 뒤 3초 안에 다음 키를 누르세요. 방향키 자체는 ← ↑ ↓ →로 표시했어요. 방향키가 섞인 조합은 설명에서 누르는 순서를 확인하세요.

Mac의 Option은 Windows·Linux의 Alt에 대응합니다. Option+B·F·D·Y·P 같은 조합은 터미널의 Option as Meta 설정이 필요해요. 한글 상태에서 키가 안 먹으면 영문 입력 상태에서도 확인해보세요.

전체 화면은 대화를 앱 안에서 스크롤하는 방식이에요. 터미널 창을 최대화한다는 뜻은 아닙니다. 일반 화면은 터미널의 스크롤 기록을 씁니다. 화면 방식과 버전에 따라 같은 키도 다르게 동작할 수 있어요.

이미 끝난 수정을 되돌릴 때는 되돌리기 메뉴를 열고, 진행 중인 답변만 멈출 때는 Esc를 누르세요.

아까 걸로 돌아가자

Esc → Esc

입력창이 비어 있을 때 Esc를 두 번 누르면, 돌아갈 시점을 고르는 메뉴가 열려요. 대화와 파일을 함께 되돌릴 수도 있고, 둘 중 하나만 복원하거나 대화 일부를 요약할 수도 있습니다. 파일 복원은 해당 시점 이후에 추적한 변경이 있을 때 선택할 수 있어요.

예를 들어제안서 페이지를 몇 번 고쳤는데 처음 구성이 더 낫다면, 입력창을 비우고 Esc를 두 번 누르세요. 돌아갈 요청을 고른 다음 파일만 복원할지, 대화도 함께 되돌릴지 정하면 됩니다.

입력창에 글이 남아 있으면 초안을 지워요. 이 글은 ↑로 다시 꺼낼 수 있습니다. 파일은 Claude가 이 대화에서 편집한 적이 있어야 복원 대상으로 잡혀요. 그 파일을 나중에 셸 명령으로 고친 부분은 되돌릴 수 있지만, 셸 명령으로만 바꾼 파일은 그대로 남습니다. 다른 세션이나 서브에이전트의 수정도 모두 복원되는 것은 아니에요.

KEYBOARD · 먼저 써볼 키#

잠깐, 거기서 멈춰

Esc

답변이나 도구 실행을 도중에 멈춥니다. 이미 끝낸 수정은 남아 있어요. 창이 열려 있다면 그 창을 닫고, 권한을 묻는 중이라면 요청을 거절합니다.

예를 들어회의록을 통째로 번역하기 시작했는데 필요한 건 요약뿐이었다면, Esc를 누르고 “결정 사항만 뽑아줘”라고 다시 요청하세요.

대기열에 넣어둔 메시지는 이어서 전달돼요. 아직 보내지 않은 초안은 이 키로 전송되지 않습니다. 입력창 아래 작업을 선택해둔 상태라면, Esc는 그 선택부터 해제해요.

KEYBOARD#

실행을 중단하거나 초안을 비우기

Ctrl+C

작업 중이면 멈추고, 작업이 없으면 쓰던 글을 비웁니다. 아무것도 실행하지 않는 상태에서 다시 누르면 Claude Code가 종료돼요.

예를 들어쓰던 요청을 처음부터 다시 적고 싶을 때 한 번 누르세요. 실수로 비웠다면 ↑로 가져올 수 있어요.

전체 화면에서 글을 선택해두었다면 복사로 동작할 수 있습니다. 창이 열려 있을 때는 두 번 눌러 그 창만 닫기도 하니, 첫 번째 키를 누른 뒤 화면 안내를 보세요.

KEYBOARD#

오늘 작업은 여기까지

Ctrl+D

빈 입력창에서 한 번 누르면 종료 안내가 나오고, 800ms 안에 다시 누르면 세션을 닫습니다.

예를 들어작업을 마치고 나갈 때 빈 입력창에서 Ctrl+D를 누른 뒤, 종료 안내를 보고 한 번 더 누르세요.

글이 남아 있는 입력창에서는 커서 뒤 글자를 지웁니다. 대화상자 안에서 두 번 누르면 세션 대신 그 창만 닫히는 경우도 있어요.

KEYBOARD#

뒤에서 일하는 에이전트도 전부 멈추기

Ctrl+X → Ctrl+K

이 세션에서 뒤로 돌려둔 서브에이전트를 모두 멈춥니다. 아티팩트 댓글에 자동으로 답하는 기능도 이 세션이 끝날 때까지 꺼져요.

예를 들어여러 에이전트에 나눠 맡긴 조사의 방향이 바뀌었다면, 하나씩 찾아 멈추는 대신 이 조합을 쓰세요.

Ctrl+X 다음 Ctrl+K를 누르고, 이 조합 전체를 3초 안에 한 번 더 눌러 확인합니다. 서브에이전트의 권한 요청이 떠 있어도 사용할 수 있어요.

KEYBOARD#

화면이 깨졌을 때 다시 그리기

Ctrl+LCmd+K

글자가 겹치거나 화면 일부가 비었을 때 화면을 다시 그려요. 쓰던 글과 대화 기록은 남아 있습니다.

예를 들어터미널 창을 줄였다 넓힌 뒤 글이 엉켜 보이면 Ctrl+L을 눌러보세요.

Cmd+K도 Claude Code에 전달되면 같은 동작을 합니다. iTerm2와 Mac 기본 터미널은 자체적으로 화면을 지우지만, Claude가 감지해 대화를 다시 그려요. 이전 버전의 전체 화면에서는 화면을 비우는 동작이었으므로 버전 차이가 있습니다.

KEYBOARD#

지금 할 일이 어디까지 끝났지?

Ctrl+T

Claude의 작업 체크리스트를 보이거나 숨깁니다.

예를 들어자료를 읽은 뒤 표를 만들기로 했다면, 체크리스트를 열어 어느 단계까지 끝났는지 보세요.

실행 중인 셸과 서브에이전트는 /tasks에서 확인해요. /theme 메뉴와 에이전트 목록에서는 Ctrl+T가 다른 기능을 합니다.

KEYBOARD#

잠시 터미널로 나갔다 오기

Ctrl+Z

macOS와 Linux 같은 Unix 환경에서 Claude Code 프로세스를 일시 정지하고 셸로 돌아갑니다. 셸에서 fg를 실행하면 다시 이어집니다.

예를 들어같은 터미널에서 다른 명령을 잠깐 실행하려면 Ctrl+Z로 나왔다가, 끝난 뒤 fg를 입력해 돌아오세요.

macOS·Linux 등 Unix 환경에서 쓰는 키예요. 뒤에서 작업을 계속 돌리고 싶다면 Ctrl+B를 쓰세요.

KEYBOARD#

단축키가 기억 안 나면

?

빈 입력창에서 ?를 누르면 단축키 도움말을 열거나 닫습니다.

예를 들어빈 입력창에서 ?를 눌러 지금 쓸 수 있는 키부터 확인하세요.

글을 쓰던 중이라면 ?가 그대로 입력됩니다. 도움말은 Esc로 닫을 수 있어요.

02

요청을 길게 쓰고 다듬을 때

엔터를 누르면 전송될까 봐 긴 요청을 다른 메모장에 먼저 쓰기도 하죠. Ctrl+J로 줄을 바꾸거나, Ctrl+G로 익숙한 편집기를 열 수 있어요.

KEYBOARD · 먼저 써볼 키#

보내지 말고 줄만 바꾸기

Ctrl+J

요청을 보내지 않고 줄을 바꿔요. 터미널에 따로 설정할 필요가 없어, 줄바꿈 키 하나만 기억한다면 이걸 쓰면 됩니다.

예를 들어“아래 회의록을 정리해줘”를 적고 Ctrl+J로 내려가세요. 다음 줄에 “담당자별 할 일도 따로 모아줘”처럼 조건을 덧붙이면 돼요.

KEYBOARD#

채팅창처럼 줄바꿈하기

Shift+Enter

iTerm2, WezTerm, Ghostty, Kitty, Warp, Apple Terminal, Windows Terminal에서는 바로 줄바꿈할 수 있어요.

예를 들어긴 요청을 조건별로 나눠 적을 때 Shift+Enter로 줄을 바꾸세요.

그 밖의 터미널은 /terminal-setup 같은 설정이 필요할 수 있어요. 줄바꿈 대신 전송된다면 Ctrl+J를 쓰면 됩니다.

KEYBOARD#

Mac에서 Option으로 줄바꿈

Option+Enter

터미널에서 Option을 Meta 키로 쓰도록 설정하면 Option+Enter로 줄바꿈합니다.

예를 들어Mac에서 Option 키 조합을 쓰고 있다면 이 키로 요청의 문단을 나눌 수 있어요.

터미널의 Option as Meta를 먼저 켜두어야 합니다.

KEYBOARD#

설정이 안 돼도 줄바꿈하기

\ → Enter

역슬래시를 하나 적은 다음 Enter를 누르면 줄이 바뀝니다. 두 키는 차례로 누르세요.

예를 들어처음 쓰는 터미널에서 Shift+Enter가 안 되면 \를 적고 Enter를 눌러보세요.

코드나 로그처럼 이미 여러 줄인 글은 그대로 붙여넣어도 됩니다.

KEYBOARD · 먼저 써볼 키#

이 초안 잠깐 맡아줘

Ctrl+S

쓰던 요청을 잠깐 보관하고 입력창을 비워요. 빈 입력창에서 다시 누르면 글뿐 아니라 커서 위치와 붙여넣은 내용도 돌아옵니다.

예를 들어제안서 요청을 거의 다 썼는데 /usage부터 확인하고 싶다면 Ctrl+S를 누르세요. 확인을 마치고 빈 입력창에서 다시 누르면 쓰던 요청이 돌아와요.

!로 쓰던 셸 명령도 원래 입력 모드로 돌아옵니다. 기록 검색 창에서는 Ctrl+S가 검색 범위를 바꾸는 키예요.

KEYBOARD · 먼저 써볼 키#

긴 요청은 익숙한 편집기에서

Ctrl+GCtrl+X → Ctrl+E

긴 요청을 기본 외부 편집기로 열어요. Claude가 물어본 내용에 직접 답을 쓰는 칸에서도 쓸 수 있습니다. 편집을 마치면 저장하고 돌아와 보내세요.

예를 들어고객사 브리프가 길어져 입력창에서 문단을 옮기기 불편하다면 Ctrl+G로 여세요.

/config에서 Show last response in external editor를 켜면 직전 답변도 # 주석으로 함께 보여요. 저장할 때 이 주석은 빠집니다.

방금 지운 문장 다시 살리기

Ctrl+_Ctrl+Shift+-

입력창에서 방금 한 편집을 취소합니다. 이전 글과 커서 위치로 돌아가요.

예를 들어조건 한 줄을 지웠다가 다시 필요해졌을 때 쓰세요.

Claude가 고친 파일을 복원하려면 빈 입력창에서 Esc를 두 번 눌러야 해요.

KEYBOARD#

예를 들어예전 요청을 찾았어도 날짜를 고쳐야 한다면 Tab으로 가져오세요. Enter를 누르면 그 내용으로 바로 실행합니다.

예를 들어현재 프로젝트에서 찾던 요청이 안 보이면 Ctrl+S로 전체 기록까지 넓혀보세요.

KEYBOARD#

상세 보기에서 쓸 키 확인

?

전체 화면의 대화 상세 보기에서 단축키 도움말을 열거나 닫습니다.

예를 들어대화 상세 보기에서 쓸 키가 생각나지 않으면 ?를 누르세요. 입력창과는 키 구성이 다릅니다.

KEYBOARD#

답변 속 표현까지 검색하기

/ → 검색어 → EnterEsc

전체 화면 상세 보기에서 /로 검색창을 열고 검색어를 적습니다. Enter로 확정하고, Esc로 취소하면 원래 보던 위치로 돌아가요.

예를 들어앞선 답변의 “환불 정책” 설명을 찾으려면 Ctrl+O로 들어가 /를 누르고 검색하세요.

KEYBOARD#

같은 단어가 나온 다음 위치로

nN

전체 화면 상세 보기에서 검색창을 닫은 뒤 n은 다음 검색 결과, 대문자 N은 이전 결과로 갑니다.

예를 들어“기한”이 여러 곳에 나오면 n으로 넘겨보고, 지나쳤다면 N으로 돌아가세요.

여기의 N은 Shift+N입니다.

KEYBOARD#

상세 보기를 한 줄씩 읽기

jk↓↑

전체 화면 상세 보기에서 j·↓는 아래, k·↑는 위로 한 줄씩 이동합니다.

예를 들어오류 로그를 한 줄씩 확인할 때 j로 내려가고 k로 돌아오세요.

KEYBOARD#

상세 보기 맨 위와 맨 아래로

gGHomeEnd

전체 화면 상세 보기에서 g·Home은 처음, G·End는 끝으로 갑니다.

예를 들어처음 요청한 조건과 마지막 결과를 비교할 때 Home과 End로 오가세요.

이 화면의 G는 Shift+G입니다.

KEYBOARD#

내가 요청한 지점만 건너뛰며 보기

{}

전체 화면 상세 보기에서 {는 이전 사용자 요청, }는 다음 사용자 요청으로 갑니다.

예를 들어도구 로그는 건너뛰고, 내가 지시를 바꾼 대목부터 확인하고 싶을 때 쓰세요.

KEYBOARD#

상세 보기 반 화면씩 이동

Ctrl+UCtrl+D

전체 화면의 대화 상세 보기에서 Ctrl+U는 반 페이지 위로, Ctrl+D는 반 페이지 아래로 이동합니다.

예를 들어긴 보고서를 읽다가 바로 앞 문단을 다시 보려면 Ctrl+U를 누르세요.

상세 보기 안에서 누르는 Ctrl+D는 아래로 스크롤합니다. 빈 입력창의 종료 키와 구분하세요.

KEYBOARD#

상세 보기 한 화면씩 이동

Ctrl+BbCtrl+FSpace

전체 화면 상세 보기에서 Ctrl+B·b는 위로, Ctrl+F·Space는 아래로 한 페이지씩 갑니다.

예를 들어수백 줄짜리 실행 결과를 Space로 넘겨 읽다가, 앞 화면을 다시 보려면 b를 누르세요.

대화 상세 보기 안에서는 Ctrl+B가 위로 한 페이지 이동하는 키입니다.

KEYBOARD#

터미널의 검색 기능으로 찾기

[

전체 화면 상세 보기에서 [를 누르면 전체 대화를 터미널의 일반 스크롤 기록으로 내보냅니다.

예를 들어터미널의 검색 기능이 익숙하다면 Ctrl+O, [ 순서로 누른 뒤 Cmd+F나 tmux 검색을 쓰세요.

상세 보기를 나오면 전체 화면으로 돌아갑니다. 터미널의 검색 키는 앱마다 달라요.

KEYBOARD#

대화 전체를 편집기로 열기

v

전체 화면 상세 보기에서 대화를 임시 파일로 써서 $VISUAL 또는 $EDITOR에 지정한 편집기로 엽니다.

예를 들어긴 조사 결과에서 같은 표현이 나온 곳을 모두 찾고 싶으면 v로 편집기를 열어 검색하세요.

KEYBOARD#

접힌 내용까지 전부 펼치기

Ctrl+E

일반 화면의 상세 보기에서 전체 내용 표시를 켜고 끕니다.

예를 들어접힌 도구 결과의 원문을 읽으려면 Ctrl+E로 펼쳐보세요.

이 토글은 일반 화면에만 있어요. 평소 입력창에서 Ctrl+E를 누르면 커서가 줄 끝으로 갑니다.

KEYBOARD#

다 읽었으면 요청창으로

qEscCtrl+CCtrl+O

상세 보기를 닫고 입력창으로 돌아옵니다.

예를 들어로그를 다 읽었으면 q로 돌아와 다음 요청을 적으세요.

전체 화면에서는 Ctrl+O로도 입력창에 돌아옵니다.

KEYBOARD#

대화 화면을 반 화면씩 올리고 내리기

PageUpPageDown

전체 화면에서 대화를 위아래로 반 화면씩 스크롤합니다.

예를 들어Claude가 작업 중일 때 앞쪽 답변을 다시 읽으려면 PageUp을 누르세요.

KEYBOARD#

대화 처음과 최신 답변으로

Ctrl+HomeCtrl+End

전체 화면에서 Ctrl+Home은 대화 처음, Ctrl+End는 최신 메시지로 갑니다. Ctrl+End를 누르면 이후 새 답변도 자동으로 따라 내려가요.

예를 들어지난 답변을 읽느라 위로 올라갔다면 Ctrl+End로 현재 작업에 돌아오세요.

MacBook의 Ctrl+Fn+→는 macOS에서 가로채므로 Claude에 도달하지 않습니다. 이 경우 맨 아래 이동 버튼을 누르거나 별도 키를 지정하세요.

KEYBOARD#

선택한 문장 복사

Ctrl+Shift+CCmd+C

전체 화면에서 선택한 글을 클립보드로 복사합니다.

예를 들어팀에 공유할 문장만 골라 복사하세요. 전체 답변을 가져와서 지우지 않아도 됩니다.

Cmd+C는 Kitty 키보드 프로토콜처럼 키를 전달하는 터미널에서 지원합니다. 선택이 있으면 Ctrl+C도 복사로 동작할 수 있어요.

KEYBOARD#

선택 영역을 키보드로 늘리기

Shift+←Shift+→Shift+↑Shift+↓

이미 선택한 글의 범위를 한 글자 또는 한 줄씩 늘립니다. 위아래 화면 끝에 닿으면 화면도 스크롤돼요.

예를 들어마우스로 고른 문장에서 마지막 글자가 빠졌다면 Shift+→로 선택을 한 칸 늘리세요.

KEYBOARD#

선택을 줄 처음이나 끝까지

Shift+HomeShift+End

전체 화면에서 선택 범위를 현재 줄 처음 또는 끝까지 확장합니다.

예를 들어선택한 문장의 뒷부분까지 필요하면 Shift+End로 줄 끝까지 늘리세요.

06

/btw로 잠깐 물어본 뒤에

/btw로 “이 용어 무슨 뜻이야?” 하고 물었다면, 답변 창에서 복사하거나 앞서 물은 답변을 다시 볼 수 있어요. 아래 키는 그 답변 창 안에서 씁니다.

KEYBOARD#

답변 읽었으면 하던 일로

SpaceEnterEsc

/btw 답변을 닫고 입력창으로 돌아옵니다.

예를 들어용어 설명을 다 읽었으면 Space를 눌러 제안서 작업으로 돌아오세요.

KEYBOARD#

긴 곁가지 답변 읽기

↑↓

/btw 답변 안을 위아래로 스크롤합니다.

예를 들어설명이 화면보다 길면 ↓로 나머지를 읽으세요.

KEYBOARD#

아까 물었던 것도 다시 보기

Shift+←Shift+→[]TabShift+Tab

Shift+←나 [는 이전 답변, Shift+→나 ]는 현재 쪽 답변으로 이동합니다. Tab·Shift+Tab으로도 같은 답변들을 돌려볼 수 있어요.

예를 들어지금 답변을 읽다가 첫 질문의 약어 설명을 다시 보고 싶어졌다면 Shift+←를 누르세요.

v2.1.257 이상 기준. Shift+화살표를 전달하지 않는 터미널에서는 [와 ]를 쓰세요.

KEYBOARD#

이 설명만 깔끔하게 복사

c

답변을 줄바꿈이 강제로 들어가지 않은 원래 Markdown으로 복사합니다.

예를 들어답변을 메일에 옮길 때 c를 누르면 터미널 폭에 맞춰 잘린 줄까지 복사되는 일을 피할 수 있어요.

KEYBOARD#

이 질문은 따로 더 파보자

f

지금까지의 대화와 이 질문·답변을 넘겨받아 별도 서브에이전트가 일을 이어갑니다. 도구도 사용할 수 있어요.

예를 들어약어의 뜻만 물었다가 관련 자료 조사까지 필요해졌다면 f로 넘기세요. 새 에이전트는 입력창 아래 패널에서 확인할 수 있습니다.

로컬 세션에서만 사용할 수 있습니다.

KEYBOARD#

앞서 물었던 질문 목록 치우기

x

현재 답변 위에 모인 이전 /btw 질문과 답변 목록을 비웁니다.

예를 들어앞서 물어본 질문이 위쪽에 많이 쌓였다면 x로 목록을 비우세요.

07

모델, 생각의 강도, 음성을 바꿀 때

쓰던 요청을 남겨둔 채 모델을 바꿀 수 있어요. 생각의 강도는 모델 선택창이나 /effort에서 조절합니다.

KEYBOARD#

이번 일에 쓸 모델 고르기

Option+P (Mac)Alt+P (Windows·Linux)

쓰던 요청을 지우지 않고 모델 선택창을 엽니다.

예를 들어긴 요청을 써놓은 뒤 모델을 바꾸고 싶어졌다면, 글을 지우지 말고 이 키로 선택창을 여세요.

Mac에서는 터미널의 Option as Meta 설정이 필요합니다.

KEYBOARD#

빠른 모드 켜고 끄기

Option+O (Mac)Alt+O (Windows·Linux)

지원하는 모델의 fast 모드를 전환합니다.

예를 들어결과를 빨리 받아야 한다면 이 키로 빠른 모드를 켠 뒤, 화면의 상태 표시를 확인하세요.

빠른 모드를 지원하는 모델과 이용 조건이 필요해요. /fast 창에서는 Tab으로 켜고 끌 수 있습니다.

KEYBOARD#

생각 모드 전환

Option+T (Mac)Alt+T (Windows·Linux)

확장 사고를 켜거나 끕니다. 항상 확장 사고를 사용하는 모델에서는 설정이 바뀌지 않아요.

예를 들어확장 사고를 선택할 수 있는 모델을 쓰고 있다면, 복잡한 검토를 맡기기 전에 켜졌는지 확인해보세요.

Opus 5.5·Sonnet 5.5·Haiku 5.5와 Fable 모델은 항상 확장 사고를 사용하므로 이 키에 반응하지 않아요. Mac에서는 Option as Meta 설정 없이도 동작합니다.

KEYBOARD#

모델을 고르며 생각의 강도 조절

←→s (모델 선택창)

←→로 effort를 낮추거나 높입니다. s는 선택한 모델을 이번 세션에만 적용합니다.

예를 들어오늘 작업에서만 다른 모델을 쓰려면 모델을 고른 뒤 s를 누르세요. 기본 모델 설정은 유지할 수 있어요.

KEYBOARD#

검토 강도만 이번 일에 맞추기

←→s (effort 슬라이더)

/effort로 연 화면에서 ←→로 강도를 조절하고, s로 현재 세션에만 적용합니다.

예를 들어오탈자 수정 다음에 복잡한 원인 분석을 맡긴다면, /effort를 열어 강도를 올려볼 수 있어요.

화살표 조절은 v2.1.284 이상, 세션 한정 적용은 v2.1.257 이상입니다.

KEYBOARD#

ultracode 선택이 보일 때 전환

Tab (effort 슬라이더)

/effort 화면에 ultracode 선택이 제공되면 Tab으로 이번 세션에서 켜거나 끕니다.

예를 들어/effort에 이 선택이 보이면 Tab으로 켜거나 끄고, 이번 작업에 쓸 상태를 확인하세요.

v2.1.284 이상이며, 모든 환경에 나타나는 옵션은 아닙니다.

KEYBOARD#

코드 색상 표시 켜고 끄기

Ctrl+T (/theme 메뉴)

테마를 고르는 화면에서 코드 구문 색상을 켜거나 끕니다.

예를 들어코드 색이 너무 복잡하게 느껴지면 /theme에서 Ctrl+T로 비교해보세요.

평소 입력창의 Ctrl+T는 작업 체크리스트를 여는 키입니다.

KEYBOARD#

말로 요청 입력하기

Space 길게한 번씩 누르기

음성 입력을 켜두면 Space로 녹음할 수 있어요. 누르고 있는 동안 말하는 방식과, /voice tap으로 한 번 눌러 시작하고 다시 눌러 끝내는 방식이 있습니다.

예를 들어회의록을 어떻게 정리할지 말로 입력하고 싶다면, 음성 입력을 켠 다음 Space로 녹음하세요.

/voice를 먼저 켜야 사용할 수 있어요.

08

백그라운드 작업과 여러 세션을 오갈 때

테스트가 오래 걸리면 뒤에서 계속 돌려두고 다른 요청을 할 수 있어요. 진행 중인 작업은 입력창 아래에서 고르거나 /tasks로 확인하세요.

KEYBOARD · 먼저 써볼 키#

이건 뒤에서 계속 돌려줘

Ctrl+BCtrl+X → Ctrl+B

진행 중인 셸 작업이나 에이전트를 뒤에서 계속 실행하게 합니다. 입력창에서는 다른 요청을 이어갈 수 있어요.

예를 들어테스트가 오래 걸리면 Ctrl+B를 누르고, 기다리는 동안 “README 초안 써줘”라고 요청하세요.

tmux에서는 Ctrl+B를 두 번 누릅니다. 백그라운드 작업을 꺼둔 환경에서는 사용할 수 없어요.

KEYBOARD#

세션 목록으로 나가기

← (빈 입력창)

빈 입력창에서 ←를 누르면 현재 세션을 백그라운드로 보내고 에이전트 목록으로 이동할 수 있어요.

예를 들어보고서 작업을 돌려둔 채 다른 프로젝트의 대화로 옮기고 싶을 때 쓰세요.

대기 중인 셸 명령이나 이동할 수 없는 메시지가 있으면 전환이 막힐 수 있어요. 일반 모드와 Vim 모드 모두에서 지원합니다.

KEYBOARD#

아래에 뜬 작업 선택하기

←→ (아래 상태 영역)

입력창 아래 상태 영역에서 옆 항목으로 선택을 옮깁니다.

예를 들어조사 결과가 입력창 아래에 여러 개 보이면 ←→로 읽을 항목을 고르세요.

KEYBOARD#

아래 작업 목록 위아래로

↑↓Ctrl+PCtrl+N

↑·Ctrl+P는 위로, ↓·Ctrl+N은 아래로 선택을 옮깁니다. 맨 위에서 위로 가면 선택을 해제해요.

예를 들어아래 에이전트 패널에서 두 번째 작업을 선택하려면 ↓로 옮기세요.

KEYBOARD#

선택한 작업 열고 나오기

EnterEsc

Enter로 아래 상태 영역의 선택 항목을 열고, Esc로 선택을 해제합니다.

예를 들어아래에서 조사 에이전트를 고른 뒤 Enter로 결과를 열어보세요.

입력창의 Enter를 다른 기능으로 바꿨어도 이 영역에서 Enter는 선택 항목을 엽니다.

KEYBOARD#

이 에이전트는 여기서 멈추자

↑↓PageUpPageDownHomeEnd

예를 들어패널의 결과가 화면 아래로 잘렸다면 PageDown으로 넘겨 읽으세요.

KEYBOARD#

Ctrl+X → ←Ctrl+X → ↑Ctrl+X → →Ctrl+X → ↓

예를 들어옆 패널의 결과가 좁게 보여 읽기 어렵다면 Ctrl+X 다음 ←로 넓히세요.

KEYBOARD#

예를 들어다 읽은 보조 패널을 화면에서 치우고 싶을 때 쓰세요.

한 글자로 여는 입력 기능

입력창 맨 앞에 /나 !를 적으면 명령 메뉴나 셸 모드로 들어갑니다. 파일을 지정할 때는 @를 써요.

KEYBOARD#

명령이나 스킬 찾기

/ (입력창 맨 앞)

예를 들어/를 적어 메뉴를 연 뒤 /compact를 찾으세요.

문장 중간의 /로 뜬 후보도 Tab으로 넣을 수 있지만, 명령 실행은 맨 앞에 있을 때 적용됩니다.

KEYBOARD#

터미널 명령 바로 실행

! (입력창 맨 앞)

!로 시작하면 셸 모드에서 명령을 직접 실행합니다. 출력이 대화에 들어가고 Claude가 이어서 설명할 수 있어요.

예를 들어! git status를 실행해 현재 파일 변경 상태를 확인하세요.

적은 명령은 Claude의 해석이나 승인을 기다리지 않고 실행됩니다.

KEYBOARD#

셸 모드에서 요청 모드로

EscBackspaceCtrl+U (빈 셸 입력창)

! 셸 모드의 입력 내용이 비었을 때 일반 입력으로 돌아옵니다.

예를 들어셸 명령을 적으려다 질문으로 바꾸고 싶어졌다면, 글을 비우고 Esc를 누르세요.

셸 모드의 Tab은 이전 ! 명령이나 슬래시가 든 파일 경로도 자동완성합니다.

KEYBOARD#

이 파일을 참고해줘

@

파일 경로 자동완성을 엽니다. 다른 세션과 메시지를 주고받는 기능이 활성화돼 있으면, @ 뒤에 한 글자 이상 적었을 때 다른 실행 중 세션도 후보로 나와요.

예를 들어@reports/에서 매출 파일을 고른 다음 “이 표를 요약해줘”라고 이어 쓰세요.

세션 후보는 v2.1.232 이상이며 해당 기능을 사용할 수 있을 때 나타납니다.

KEYBOARD#

이름으로 이모지 넣기

:

:name: 형식으로 이모지를 넣거나 콜론 뒤 두 글자 이상 적어 후보를 봅니다.

예를 들어가벼운 안내문 초안에 :smile:을 넣어보세요.

v2.1.217 이상에서 지원합니다.

Vim: 입력 방식과 이동

Vim 편집은 /config의 Editor mode에서 켭니다. Vim의 대문자 명령은 Shift를 눌러 입력하고, gg처럼 붙여 적힌 글자는 차례로 누르세요.

VIM#

입력을 멈추고 이동 모드로

EscCtrl+[

INSERT 또는 VISUAL에서 NORMAL 모드로 나옵니다. 이 모드에서는 글자 키가 이동이나 편집 명령이 돼요.

예를 들어단어를 고치려면 Esc로 NORMAL에 들어간 뒤 w로 이동하세요.

Kitty 키보드 프로토콜에서 Ctrl+[를 쓰려면 v2.1.242 이상이어야 합니다. INSERT·VISUAL에서 Esc를 누르면 먼저 NORMAL로 바뀌어요.

VIM#

어디부터 글을 쓸까?

iIaA

i는 커서 앞, I는 줄 처음, a는 커서 뒤, A는 줄 끝에서 INSERT 모드로 들어갑니다.

예를 들어줄 끝에 “표로 정리해줘”를 붙이려면 A를 누르세요.

VIM#

위나 아래에 새 줄 열기

oO

o는 현재 줄 아래, O는 위에 빈 줄을 만들고 글을 쓰기 시작합니다.

예를 들어조건 목록에 한 줄을 끼워 넣으려면 그 위 줄에서 o를 누르세요.

VIM#

글자나 줄 단위로 선택

vV

v는 글자 단위, V는 줄 단위 VISUAL 모드를 시작합니다.

예를 들어한 문장 일부만 고치려면 v, 조건 한 줄 전체를 다루려면 V를 쓰세요.

VIM#

손을 옮기지 않고 이동

hjklSpace

h는 왼쪽, j는 아래, k는 위, l·Space는 오른쪽으로 이동합니다.

예를 들어방향키 대신 h와 l로 커서를 문장 안에서 옮기세요.

입력의 위아래 끝에서는 j·k 또는 ↑↓로 입력 기록을 오갑니다. k·↑는 이전, j·↓는 다음 기록이에요.

VIM#

단어 단위로 이동

web

w는 다음 단어 처음, e는 단어 끝, b는 이전 단어 처음으로 갑니다.

예를 들어긴 요청에서 잘못 적은 단어를 b로 찾아가세요.

VIM#

줄의 처음·끝·본문 처음으로

0$^

0은 줄 처음, $는 줄 끝, ^는 앞쪽 공백 다음 첫 글자로 이동합니다.

예를 들어들여쓰기된 목록의 글자 시작으로 가려면 ^를 누르세요.

VIM#

입력 전체의 앞과 뒤로

ggG

gg는 입력 맨 처음, G는 마지막 줄 처음으로 이동합니다.

예를 들어여러 문단짜리 요청의 첫 조건으로 돌아가려면 g를 두 번 누르세요.

VIM#

이 줄의 특정 글자로 바로

f{글자}F{글자}t{글자}T{글자}

현재 줄에서 f는 커서 뒤의 해당 글자, F는 앞의 해당 글자로 이동해요. t는 뒤쪽 글자 직전, T는 앞쪽 글자 직후에 멈춥니다.

예를 들어같은 줄에서 다음 쉼표로 가려면 f 다음 쉼표를 누르세요.

{글자}는 누를 실제 글자 자리입니다. 중괄호까지 적지 않아요.

VIM#

방금 찾은 글자 다시 찾기

;,

;는 마지막 f·F·t·T 이동을 같은 방향으로 반복하고, 쉼표는 반대 방향으로 반복합니다.

예를 들어f 다음 쉼표를 눌러 첫 쉼표에 갔다면, ;로 다음 쉼표를 찾고 ,로 반대쪽을 찾으세요.

VIM#

짝이 되는 괄호로 이동

%

(), [], {}의 반대쪽 괄호로 갑니다. 커서가 괄호에 없으면 같은 줄의 다음 괄호부터 찾습니다.

예를 들어긴 JSON 조건에서 여는 중괄호와 닫는 중괄호를 오가며 확인하세요.

v2.1.301 이상입니다.

VIM#

기록 검색과 도움말

/? (NORMAL 모드)

NORMAL에서 /는 역방향 기록 검색을 열고, ?는 도움말을 엽니다.

예를 들어예전 요청을 찾으려면 /를, 슬래시 명령을 적으려면 Esc 다음 i 다음 /를 누르세요.

일반 입력창에서 /로 명령을 여는 동작과 달라요.

Vim: 지우고 고치고 붙이기

아래 키는 NORMAL 모드 기준입니다. d는 삭제, c는 지우고 새로 입력, y는 복사를 뜻해요. 예시의 영문 키는 차례로 누릅니다.

VIM#

한 글자만 고치기

xr{글자}

x는 커서의 글자를 지우고, r 다음 글자는 현재 글자를 그 글자로 바꿉니다.

예를 들어영문·숫자로 된 코드 한 자리만 틀렸다면 그 글자에서 r을 누르고 올바른 글자를 적으세요.

VIM#

줄 전체나 뒤쪽 지우기

ddD

dd는 현재 줄, D는 커서부터 줄 끝까지 지웁니다.

예를 들어필요 없어진 조건 한 줄은 d를 두 번 눌러 빼세요.

VIM#

단어 범위 지우기

dwdedb

dw는 다음 단어 처음까지, de는 단어 끝까지, db는 앞쪽 단어로 이동하는 범위를 지웁니다.

예를 들어영어 요청에서 잘못 쓴 단어를 dw로 지우세요.

VIM#

특정 글자까지 한 번에 지우기

df{글자}dt{글자}

df는 다음 해당 글자를 포함해서 지우고, dt는 그 글자 직전까지 지웁니다.

예를 들어쉼표 앞의 설명을 걷어내되 쉼표는 남기려면 d, t, 쉼표를 차례로 누르세요.

VIM#

여러 줄 범위 지우기

djdkdggdG

dj는 현재 줄과 아래 줄, dk는 현재 줄과 위 줄을 지웁니다. dgg는 첫 줄까지, dG는 마지막 줄까지 지워요.

예를 들어요청 뒷부분을 통째로 다시 쓰고 싶다면 해당 줄에서 dG를 쓰세요.

VIM#

줄 앞부분 삭제·수정·복사

d0c0y0

커서부터 줄 처음까지 d0는 삭제, c0는 지우고 입력, y0는 복사합니다.

예를 들어앞부분의 조건만 다시 쓰려면 c0 뒤 새 문장을 입력하세요.

v2.1.281 이상입니다.

VIM#

짝 괄호까지 삭제·수정·복사

d%c%y%

%로 이동할 짝 괄호까지의 범위를 삭제하거나 고치거나 복사합니다.

예를 들어커서를 여는 괄호에 두고 y%로 괄호 묶음을 복사하세요.

v2.1.301 이상. 괄호 안쪽만 고치려면 아래의 ci( 같은 텍스트 객체도 쓸 수 있어요.

VIM#

지우고 바로 새로 쓰기

ccCcwcecb

cc는 현재 줄, C는 커서부터 줄 끝을 지우고 바로 입력을 시작합니다. cw·ce·cb는 각각 단어, 단어 끝, 앞쪽 단어 범위를 고칠 때 씁니다.

예를 들어조건 한 줄을 새로 쓰려면 cc를 누르고 새 문장을 적으세요.

VIM#

한 글자나 한 줄을 비우고 입력

sS

s는 커서의 한 글자를, S는 현재 줄을 지우고 INSERT 모드로 들어갑니다.

예를 들어한 글자를 지운 뒤 그 자리부터 새로 쓰고 싶다면 s를 누르세요.

VIM#

줄이나 단어 복사

yyYywyeyb

yy·Y는 현재 줄, yw·ye·yb는 각 단어 이동 범위를 복사합니다.

예를 들어비슷한 조건을 하나 더 적으려면 yy로 줄을 복사하세요.

VIM#

복사·삭제해둔 글 붙이기

pP

p는 커서 뒤, P는 커서 앞에 보관된 글을 붙입니다.

예를 들어yy로 복사한 줄을 p로 붙인 뒤 날짜만 고치세요.

Vim에서 복사하거나 지운 내용을 가져옵니다. 클립보드에 있는 글을 붙이는 키와는 달라요.

VIM#

줄 들여쓰기 맞추기

>><<

>>는 들여쓰기를 늘리고, <<는 줄입니다.

예를 들어조건 목록을 한 단계 안으로 넣으려면 >를 두 번 누르세요.

VIM#

다음 줄과 이어 붙이기

J

현재 줄과 다음 줄을 합칩니다.

예를 들어붙여넣은 요청이 두 줄로 나뉘었다면 앞줄에서 J로 합치세요.

VIM#

취소하거나 같은 수정 반복

u.

u는 편집 취소, 마침표는 마지막 변경을 반복합니다.

예를 들어단어를 고친 뒤 같은 수정을 다시 해야 한다면, 다음 위치로 옮겨 .을 누르세요.

Vim: 단어·따옴표·괄호 안쪽만 고치기

텍스트 객체는 고칠 범위를 뜻해요. d·c·y 뒤에 붙여 쓰면 됩니다. ci"는 큰따옴표 안을 비우고 새로 적고, ya(는 괄호를 포함해 복사하는 식이에요.

VIM#

단어 안쪽과 주변까지

iwawiWaW

iw는 단어 안쪽, aw는 주변 공백을 포함한 단어입니다. iW·aW는 공백으로 나뉜 덩어리 전체를 다룹니다.

예를 들어ciw로 현재 단어만 바꾸세요. 공백 없는 파일 경로를 통째로 지울 때는 daW를 쓸 수 있어요.

VIM#

따옴표 안쪽과 따옴표째

i"a"i'a'

i는 따옴표 안 내용만, a는 따옴표를 포함해 다룹니다. 큰따옴표와 작은따옴표 모두 지원해요.

예를 들어고객사 이름을 "A사"로 표시라고 적었다면, 따옴표 안에 커서를 두고 ci"를 누르세요. 새 이름을 적어도 따옴표는 남습니다.

VIM#

괄호 속 내용만 다루기

i(a(i[a[i{a{

i는 괄호 안쪽, a는 괄호를 포함한 묶음입니다. 소괄호, 대괄호, 중괄호를 지원합니다.

예를 들어부연 설명만 바꿀 때는 ci(로 괄호 안을 비우고 쓰세요. JSON 묶음을 괄호째 복사하려면 ya{를 누르면 됩니다.

Vim: 선택 영역을 한꺼번에 편집하기

v 또는 V로 선택한 뒤 아래 키를 누릅니다. VISUAL 모드의 u는 소문자 변환이므로 NORMAL 모드의 편집 취소와 다릅니다.

VIM#

고른 부분 삭제·복사·교체

dxycsp

d·x는 선택 삭제, y는 복사, c·s는 지우고 입력, p는 보관된 글로 선택 영역을 교체합니다.

예를 들어v로 조건 일부를 고른 뒤 c를 눌러 새 조건으로 바꾸세요.

VIM#

선택한 글자를 모두 같은 글자로

r{글자}

선택 영역의 글자 각각을 지정한 글자로 바꿉니다.

예를 들어짧은 선택 영역을 모두 x로 채우려면 r 다음 x를 누르세요.

VIM#

대소문자 한 번에 바꾸기

~uU

~는 대소문자를 뒤집고, u는 소문자, U는 대문자로 바꿉니다.

예를 들어선택한 영문 약어를 대문자로 맞추려면 U를 누르세요.

VIM#

여러 줄 들여쓰기와 합치기

예를 들어조건 몇 줄의 들여쓰기를 맞추려면 V로 줄들을 고른 뒤 >를 누르세요.

VIM#

선택 방식 바꾸거나 나가기

vVEsc

글자 선택과 줄 선택을 전환하거나, 같은 선택 모드의 키를 다시 눌러 나옵니다. Esc도 NORMAL로 나와요.

예를 들어글자 일부를 고르다 줄 전체가 필요해지면 V로 바꾸세요.

Ctrl+V로 사각형을 고르는 블록 VISUAL은 지원하지 않아요. 질문의 Other 입력칸에서 글을 쓰던 중이라면 Esc는 우선 NORMAL로 바꾸고, 한 번 더 누르면 질문을 취소합니다.

내 환경에 맞추기

키가 안 먹거나, 바꾸고 싶다면

키가 예상과 다르게 동작하면 지금 어느 창을 보고 있는지 확인해보세요. Ctrl+S 하나도 입력창에서는 초안 보관, 기록 검색에서는 범위 변경, 에이전트 보기에서는 세션 묶기입니다.

Mac과 터미널에서 자주 걸리는 부분

  • Mac에서 Ctrl을 전부 Cmd로 바꾸면 안 됩니다. Ctrl+C는 Control+C, Option+P는 Option+P로 눌러요.
  • Option 단축키가 문자를 입력한다면 터미널에서 Option as Meta를 켜세요. Option+T는 이 설정 없이도 작동합니다.
  • MacBook의 Fn+↑·↓는 PageUp·PageDown, Fn+←·→는 Home·End입니다. Ctrl+Fn+→는 macOS가 가로채므로 맨 아래 이동은 화면 버튼이나 다른 키를 쓰세요.
  • tmux의 Ctrl+B는 접두 키라 두 번 눌러 보내야 합니다. GNU screen에서는 Ctrl+A가 겹칠 수 있어요.
  • Shift+Enter나 Ctrl+Enter가 구분되지 않는 터미널이라면 줄바꿈은 Ctrl+J, 즉시 보내기는 Ctrl+X 다음 Ctrl+S를 쓰세요.

자주 쓰는 동작에 다른 키 붙이기

/keybindings를 실행하면 ~/.claude/keybindings.json을 만들거나 엽니다. 저장하면 재시작 없이 적용돼요. 아래 예시를 직접 추가하면 입력창에서 Alt+G, Mac에서는 Option+G로 /compact를 실행할 수 있어요. 기본으로 지정된 키는 아닙니다.

keybindings.json · 사용자 설정 예시
{
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "meta+g": "command:compact"
      }
    }
  ]
}

이미 설정 파일이 있다면 기존 bindings 배열에 이 블록을 합쳐주세요. meta는 Mac에서 Option, 다른 환경에서 Alt를 뜻합니다. 키 이름은 영문으로, Shift를 써야 한다면 shift+g처럼 명시해요.

일반 설정의 키 이름은 대소문자를 구별하지 않습니다. 그래서 플러그인 메뉴의 i·f 같은 키는 Shift 없이 눌러요. 반면 Vim, 전체 화면 대화 상세 보기처럼 대소문자별 동작을 안내하는 화면에서는 G·N 등의 대문자를 구별해야 합니다.

바꿀 수 없는 키와 기본 키가 없는 동작

Ctrl+C와 Ctrl+D는 예약된 중단·종료 키입니다. Ctrl+M은 Enter, Ctrl+[는 Esc, Ctrl+I는 Tab으로 전달됩니다. Ctrl+H는 터미널이 보내는 Backspace 신호이며 Windows 설정에 따라 해석이 달라요. Caps Lock은 터미널 앱에 전달되지 않습니다.

Alt+B·F·D·Y 같은 단어 이동·삭제 기록 키는 이 설정 파일로 바꿀 수 없습니다. Vim의 이동·편집 키 자체도 이 파일로 바꾸지 못합니다. INSERT에서 jj 같은 두 글자를 Esc로 쓰고 싶다면 별도 vimInsertModeRemaps 설정이 필요해요. 기본 설정에서 jj가 Esc인 것은 아닙니다.

다음 패널로 전환하기, 선택 영역 지우기, 한 화면 스크롤 같은 일부 동작은 기본 키가 없습니다. unbound는 “키를 아직 배정하지 않았다”는 뜻이에요. 마우스 휠의 위·아래 스크롤도 키보드 조합과는 별개입니다.
