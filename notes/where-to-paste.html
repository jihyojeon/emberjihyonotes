대체 어디에요?

AI 릴스를 따라 하다가 "여기 붙여넣으세요"에서 막혔다면,
시작하기 전에 딱 세 가지만 알면 돼요.

말로 하는 부탁은 채팅창, 스킬이나 커넥터는 설정, 회색 코드 블록 속 영어 명령어는 터미널이에요. 이 노트는 릴스에서 말한 순서 그대로, 웹·앱·폰 앱 차이 → 붙여넣는 곳 세 군데 → 스킬과 MCP로 정리했어요.

첫째

웹, 데스크톱 앱, 폰 앱

클로드도 챗GPT도 쓰는 방법이 세 가지예요. 채팅창은 셋 다 똑같이 있어요.

어디서어떻게 들어가요이럴 때 좋아요
웹크롬 같은 브라우저 주소창에 claude.ai, chatgpt.com설치 없이 바로 시작할 때
데스크톱 앱컴퓨터에 프로그램을 설치내 컴퓨터 파일까지 다루고 싶을 때
폰 앱앱스토어에서 설치말로 묻거나 사진 찍어서 물어볼 때
  • 웹은 설치가 필요 없어서 처음 시작하기 제일 쉬워요.
  • 데스크톱 앱은 웹에서 되는 건 다 되고, 내 컴퓨터와 연결되는 기능이 더 있어요. 클로드 데스크톱 앱의 Code 탭에서는 터미널을 열지 않고도 클로드 코드를 쓸 수 있어요.
  • 폰 앱은 이동 중에 음성으로 대화하거나, 눈앞에 있는 걸 찍어서 물어볼 때 편해요.

같은 계정으로 로그인하면 대화 기록은 어디서든 이어서 볼 수 있어요.

둘째

어디에 붙여넣냐: 딱 세 군데

"이거 붙여넣으세요"라는 말 하나가 사실 세 가지를 뜻해요. 붙여넣을 내용을 보면 어디에 넣을지 알 수 있어요.

어디뭘 넣어요이렇게 생겼어요
채팅창말로 하는 부탁"이 글 요약해줘"
설정한 번 넣어두고 계속 쓰는 것스킬 zip 파일, 커넥터 연결 버튼
클로드 코드·코덱스는 스킬 링크를 채팅창에 줘도 돼요
터미널영어 명령어회색 코드 블록 안 npm install ...

  1. 채팅창

    AI한테 말로 하는 부탁은 전부 여기에 써요. 릴스에서 알려주는 "프롬프트"도 대부분 채팅창에 넣는 거예요. 영어로 길게 쓰여 있어도 사람한테 말하듯 쓴 문장이면 채팅창이에요.

    부탁할 때는 세 가지를 같이 주면 답이 훨씬 좋아져요. 지금 내 상황, 참고할 자료, 원하는 결과 모양이요.

    채팅창에 붙여넣기
    나는 회사에서 매주 회의록을 정리해서 팀에 공유해.
아래 회의 메모를 읽고, 결정된 것과 할 일을 나눠서 정리해줘.
할 일은 담당자와 마감일이 보이게 표로 만들어줘.

[회의 메모 붙여넣기]

  2. 설정

    스킬이나 커넥터처럼 한 번 넣어두고 계속 쓰는 건 설정에 넣어요. 클로드에서는 둘 다 왼쪽 메뉴의 Customize 안에 있고, 챗GPT는 설정의 앱(Apps) 메뉴에서 연결해요. 스킬과 커넥터가 뭔지, 어떻게 넣는지는 아래 셋째에서 자세히 설명할게요.

  3. 터미널

    터미널은 컴퓨터에 글자로 명령하는 창이에요. 릴스나 블로그에서 회색 박스로 보여주는 걸 코드 블록이나 스니펫이라고 하는데요, 그 안에 든 영어 명령어는 터미널에 넣는 거예요.

    터미널에 붙여넣기 · 클로드 코드 설치
    npm install -g @anthropic-ai/claude-code

    명령어는 짧고, npm, git, -g, ~/처럼 영어 단어와 기호가 섞여 있어요. 박스 위에 bash, sh, terminal이라고 쓰여 있으면 확실히 터미널이에요. 단, 코드 블록 안에 프롬프트(말로 하는 부탁)가 들어 있을 때도 있어요. 그건 채팅창에 넣으면 돼요.

    터미널 명령어를 채팅창에 넣으면 AI가 그 명령어를 설명만 해주고, 실행은 안 돼요.

    터미널 여는 법

    • 맥: ⌘ + Space를 누르고 "터미널"을 검색해요.
    • 윈도우: 시작 메뉴에서 "터미널"을 검색해요. 안 나오면 "PowerShell"을 열어요.

    클로드 코드와 코덱스

    클로드 코드(Anthropic)와 코덱스(OpenAI)는 터미널 안에서 일하는 AI예요. 채팅 AI는 대답을 해주지만, 이 둘은 내 컴퓨터 폴더 안에서 파일을 직접 만들고 고쳐요. 코딩을 몰라도 "이 폴더 사진들 날짜별로 정리해줘" 같은 일을 시킬 수 있어요. 터미널이 낯설면 클로드 데스크톱 앱의 Code 탭에서 시작해도 돼요.

    ✳
    모르는 명령어는 바로 실행하지 마세요

    터미널 명령어는 내 컴퓨터에서 바로 실행돼요. 처음 보는 명령어라면 실행하기 전에 채팅창에 붙여넣고 "이 명령어 뭐 하는 거야?"라고 먼저 물어보세요. 이때는 채팅창에 넣는 게 맞아요.

마지막으로

스킬과 MCP

릴스에서 제일 많이 나오는 두 단어예요. 하나는 AI에게 일하는 방법을 알려주는 것, 다른 하나는 AI를 다른 앱과 연결하는 거예요.

  1. 스킬: AI한테 주는 업무 매뉴얼

    "이 일은 이렇게 해"라고 적어둔 폴더예요. 이메일 다듬기, 보고서 양식처럼 반복하는 일을 스킬로 넣어두면, 관련된 부탁을 할 때 AI가 알아서 꺼내 써요.

    클로드 웹·앱에서 넣는 법

    1. 왼쪽 메뉴에서 Customize → Skills로 들어가요.
    2. + 버튼을 누르고 스킬 만들기에서 업로드를 골라요.
    3. 스킬 zip 파일을 올리면 목록에 생기고, 켜고 끌 수 있어요.
    ✳
    Skills 메뉴가 안 보이면

    Settings → Capabilities에서 코드 실행과 파일 만들기가 켜져 있는지 확인하세요. 스킬은 이 기능 위에서 돌아가요. zip 파일은 스킬 폴더째로 압축해야 해요. 폴더 안 파일만 꺼내서 압축하면 스킬로 인식이 안 돼요.

    클로드 코드·코덱스라면: 채팅창에 링크 주고 "설치해줘"

    클로드 코드나 코덱스를 쓴다면 더 쉬워요. 설정에 들어갈 필요 없이, 채팅창에 스킬 링크를 붙이고 설치해달라고 부탁하면 바로 설치해줘요. 클로드 데스크톱 앱의 Code 탭이나 코덱스 앱의 채팅창에서도 똑같이 돼요.

    클로드 코드 · 코덱스 채팅창에 붙여넣기
    https://github.com/blader/humanizer
이 스킬을 지금 사용 중인 도구에 설치해줘. 참고 파일도 함께 설치해줘.

    첫 줄의 링크만 설치하고 싶은 스킬 주소로 바꾸면 돼요. 설치 위치나 접근 권한을 물어보면 내용을 읽어보고 허락하세요. 스킬은 도구마다 따로 설치해요. 클로드 코드에 설치했다고 코덱스에도 생기지는 않아요.

    ✳
    일반 채팅에서는 이 방법이 안 돼요

    클로드 웹이나 앱의 일반 채팅창에 같은 문장을 넣으면 설치 방법을 설명만 해줘요. 일반 채팅에서는 위의 Customize → Skills에서 zip을 올려야 해요. 스킬 설치를 부탁할 수 있는 건 내 컴퓨터에서 직접 일하는 클로드 코드와 코덱스예요.

    이렇게 설치한 스킬을 실제로 써본 예시는 AI 이메일 스킬 노트에 적어뒀어요.

  2. MCP: AI한테 다른 앱 열쇠 주기

    노션, 구글 드라이브, 지메일 같은 앱을 연결하면 AI가 거기서 직접 자료를 찾아보고 일해요. 이렇게 AI와 다른 앱을 잇는 방식이 MCP예요. 클로드와 챗GPT 화면에서는 보통 커넥터나 앱이라는 이름으로 보여요. 릴스에서 "MCP 연결하세요"라고 하면 대부분 이 얘기예요.

    • 클로드: Customize → Connectors에서 연결해요. 대화마다 켜고 끄려면 채팅창 왼쪽 아래 + 버튼에서 Connectors를 눌러요.
    • 챗GPT: 설정의 앱(Apps) 메뉴에서 연결해요. 버전에 따라 이름이 플러그인(Plugins)으로 보일 수도 있어요.

    커넥터는 붙여넣을 게 없어요. 연결 버튼을 누르고 로그인해서 허락하면 끝이에요.

    ✳
    연결 전에 권한을 한 번 읽어보세요

    커넥터를 켜면 AI가 그 앱에서 내가 볼 수 있는 자료를 읽을 수 있어요. 어떤 권한을 달라고 하는지 확인하고, 모르는 곳에서 만든 커넥터는 연결하지 마세요.

더 알아두면 좋아요

컨텍스트: AI가 지금 보고 있는 것

컨텍스트는 AI가 답할 때 보고 있는 내용 전부를 말해요. 지금 대화에서 내가 쓴 말, 올린 파일, AI가 한 대답이 다 여기에 들어가요.

  • 새 채팅은 처음부터예요. 어제 대화에서 준 자료를 오늘 새 채팅에서 물어보면 몰라요. 필요한 자료는 다시 줘야 해요.
  • 대화가 너무 길어지면 앞부분을 놓쳐요. 한 대화에서 주제가 여러 번 바뀌었다면 새 채팅을 여는 게 나아요.
  • 자료를 많이 줄수록 답이 좋아져요. "보고서 써줘"보다 "이 자료로, 이 양식에 맞춰서"가 훨씬 정확해요.

메모리 기능이 켜져 있으면 AI가 나에 대한 정보를 조금 기억하기도 해요. 그래도 그날 작업할 자료는 대화에 직접 주는 게 확실해요.

반복 설명 줄이기

매번 설명하기 귀찮다면

  • 프로젝트: 클로드와 챗GPT 둘 다 있어요. 프로젝트에 지침과 자료를 한 번 넣어두면, 그 안에서 여는 모든 대화에 적용돼요. "나는 마케터고, 보고서는 이 양식으로 써" 같은 걸 넣어두기 좋아요.
  • CLAUDE.md / AGENTS.md: 클로드 코드는 작업 폴더에 있는 CLAUDE.md 파일을, 코덱스는 AGENTS.md 파일을 먼저 읽어요. 그 폴더에서 일할 때 지켜야 할 규칙을 적어두면 돼요.

Q&A

자주 막히는 것

코드 블록 안에 든 건 무조건 터미널이에요?
아니요. 영어 명령어면 터미널이고, 사람한테 말하듯 쓴 부탁이면 채팅창이에요. 박스 위에 bash나 terminal이라고 쓰여 있으면 터미널이에요.
명령어를 채팅창에 넣었는데 아무 일도 안 일어나요
정상이에요. 일반 채팅창은 명령어를 실행하지 않아요. 터미널을 열어서 다시 붙여넣으세요.
터미널에 붙여넣었더니 "command not found"가 떠요
명령어에 필요한 프로그램이 아직 안 깔려 있다는 뜻이에요. 예를 들어 npm을 쓰려면 Node.js가 먼저 깔려 있어야 해요. 에러 메시지를 채팅창에 붙여넣고 "이거 어떻게 해결해?"라고 물어보세요.
스킬 링크를 일반 클로드 채팅에 넣었는데 설치가 안 돼요
일반 채팅은 내 컴퓨터에 파일을 설치하지 못해요. 링크로 설치를 부탁하는 건 클로드 코드(데스크톱 앱 Code 탭 포함)나 코덱스에서 하고, 일반 채팅에서는 Customize → Skills에 zip을 올리세요.
무료 요금제에서도 다 돼요?
요금제마다 쓸 수 있는 기능이 달라요. 메뉴가 안 보이면 요금제 안내 페이지에서 확인해 보세요.
